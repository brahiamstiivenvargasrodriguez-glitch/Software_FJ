Software FJ – Sistema Integral de Gestión de Clientes, Servicios y Reservas

Descripción del proyecto

Software FJ es un sistema desarrollado en Python que permite gestionar clientes, servicios y reservas mediante programación orientada a objetos. El proyecto implementa validaciones, manejo de excepciones personalizadas y registro de eventos y errores en archivos de log.

Objetivo

Desarrollar una aplicación modular que permita administrar clientes y servicios, realizar reservas, calcular costos y controlar errores, aplicando los fundamentos de la programación orientada a objetos.

Tecnologías utilizadas

Python 3.14
Programación orientada a objetos (POO)
Visual Studio Code
Funcionalidades

Registro y validación de clientes.
Creación y administración de servicios.
Gestión de reservas.
Cálculo de costos con descuentos e impuestos.
Validación de datos.
Manejo de excepciones personalizadas.
Registro de eventos y errores mediante archivos de log.
Estructura del proyecto

"Main.py": archivo principal y ejecución de pruebas.
"Modelos/": clases y lógica de clientes, servicios y reservas.
"Utilidades/": excepciones personalizadas y sistema de registro.
